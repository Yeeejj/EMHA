# R4.6 full-run sheet: Colab + Kaggle split (Deviation 3)

Drafted 2026-10-22. Replaces the session table in R4.5 section 5. The 20
CNN-path draws are split: **Colab A100 draws 0–11, Kaggle T4 x2 draws 12–19**,
running at the same time. Everything else is as in R4.5. No metric is read
before the full run finishes (EVALUATION_PROTOCOL.md section 7).

Every Colab session: `notebooks/colab_bootstrap.ipynb` from GitHub main,
`MODE = "run"`, `SUBSET = None`, `AUTO_DISCONNECT = True`, the same
`DRIVE_ZIP` / `DRIVE_OUTPUT_ROOT`, secret `GITHUB_TOKEN` on. Keep the tab open
and the PC awake (Pay As You Go has no background execution). After a
disconnect, **Run all again with the same settings**: markers and cached draws
skip finished work.

Every Kaggle version: `notebooks/kaggle_bootstrap.ipynb`, dataset
`emha-crops` attached, Internet on, secret `GITHUB_TOKEN` attached,
Accelerator **GPU T4 x2**, `SUBSET = None`, `ANALYSIS = "primary"`,
`DEVICE = "cuda"`. Run it with **Save Version → Save & Run All (Commit)**: it
runs in the background (no open tab needed). A version stops at 12 hours, so
each one gets at most 4 draws.

## Before K1: check the Kaggle dataset is the full one

Cell 5 of the Kaggle notebook prints `MANIFEST.txt`. Its folds/labels SHA-256
lines must match the ones S1 printed from the Drive zip (cell 7). If they
differ, the draws cannot be merged (`merge_draws` refuses) — upload the same
`emha-crops.zip` as a new dataset version first.

## Time and units

Critical path ≈ S1 0.5 h + S2 4–6 h + 12 draws on A100 (about 1.2–2 h each,
depending on `nproc`) + merge + S5 2.5 h ≈ **22–33 h**. Kaggle's 8 draws plus
features take about 13–19 h of background time in parallel and use about
13–19 of Kaggle's weekly GPU hours.

Colab A100 hours ≈ 4–6 + 14–24 + 2.5 ≈ 21–33 h ≈ **115–180 units** at
5.4/h, plus two short CPU sessions. One more 100-unit pack (200 in total) is
enough unless the draws run at the slow end; check the balance after the
first two draws.
