================================================================================
1. SCOPE
================================================================================

This study asks whether offline handwriting and drawings carry information
about a person's self-reported emotional state at the time of writing. The
target is a binary label, HAPPY or SAD, taken from a questionnaire completed
in the same session. It is a concurrent, self-reported state. It is not a
diagnosis, and the models are not screening or clinical tools.

3. TASKS, SCANNING, AND CROPPING
================================================================================

Each participant completed a drawing page and a writing page.

Drawing page: four drawings, coded D1 to D4: D1 circles, D2 dots, D3 "Draw
a Person in the Rain", and D4 "Draw a House and a Tree". [MISSING: exact
drawing instructions and any time limits]

Background of the two projective drawings. D3 follows the
Draw-a-Person-in-the-Rain task, in which the rain is read as a stressor and
protection such as an umbrella as coping [CITE: Draw-a-Person-in-the-Rain,
original source and a scoring system]. One computer-scoring study reported
that self-reported stress was associated with the number, spacing and area
of the raindrops [CITE: Social Behavior and Personality, computer scoring of
the DAPR], while another found no association between the stress
indicators and a self-report stress scale [CITE: Willis, Joy and Kaiser
2010, The Arts in Psychotherapy]. D4 is taken from the House-Tree-Person
family [CITE: Buck, House-Tree-Person]. A 2022 meta-analysis linked several
house and tree characteristics to mental disorders in general [CITE:
Frontiers in Psychiatry 2022 meta-analysis of HTP], while a large 2022
study found no reliable association between the standard HTP indicators
and mental health problems [CITE: Acta Psychologica 2022, HTP and deep
learning]. Reviews judge the validity evidence for figure drawings to be
weak [CITE: Lilienfeld, Wood and Garb 2000]. In this study the drawings are
not scored with these systems; they are measured with the handcrafted
drawing features (section 5.1) and used as images by the models.
[CHECK: verify each source in full text before citing]

Writing page: five emotion words (content, disconnected, melancholic,
optimistic, vibrant), each written three ways: with the non-dominant left
hand (LH), with the dominant right hand (RH), and in uppercase (UC). This
gives 15 word boxes. The page also holds five cursive passages, CS1 to CS5.
[MISSING: cursive passage text, and whether UC was written with the right
hand]

This gives 24 crops per participant: 4 drawing, 15 word, and 5 cursive.

All pages were printed on one printer, completed with one pen model, and
scanned on one scanner. [MISSING: printer, pen, and scanner make and model;
paper type] Scans are 1700 x 2200 pixels at 200 dpi, checked on the files
themselves.

Each box was cut at a fixed position and a fixed pixel size per exercise:

    Drawings   D1 674 x 669, D2 662 x 674, D3 675 x 1016, D4 664 x 1016
    Words      368 x 118 (all 15 boxes)
    Cursive    1342 x 174 (all 5 boxes)

The top drawing row is shorter than the bottom row, so D1 and D2 differ in
size from D3 and D4. Crop sizes were verified on every file against these
values. Each crop was checked by hand to confirm that every box was
answered. [MISSING: who checked completeness and how disagreements were

them.

Current counts: 2,400 crops are indexed (100 participants x 24 crops: 400

================================================================================
4. PREPROCESSING
================================================================================

Each crop is converted to grayscale. Uneven paper background is flattened by
dividing the image by a large blur of itself (51-pixel kernel), so paper
lands near white and ink keeps its darkness. A 3 x 3 median filter removes
scanner noise. Each task family is then scaled by one fixed factor (drawing
0.44, word 1.0, cursive 0.33) and padded with white to a fixed canvas
(drawing 297 x 448, word 368 x 118, cursive 443 x 58). The factors were set
from the measured crop sizes so that the long side of the largest drawing
and cursive crops lands near 448 pixels; word crops keep their native size.
The stored image is inverted (ink bright on dark).

Three common steps were deliberately avoided:

  - Binarization. Thresholding to black and white would discard ink
    darkness and pressure-related variation in stroke intensity, which are
    candidate signals [CITE: pen pressure and emotion]. Otsu thresholding is
    used only to compute descriptive statistics, never on a model input
    [CITE: Otsu].
  - Deskewing. Rotating text to a horizontal baseline would erase baseline
    slope and slant, which graphology links to mood [CITE: baseline
    direction and mood]. Baseline angle is measured on each word and
    cursive crop without rotating it.
  - Stretch-resizing. Resizing every crop to a square would distort aspect
    ratio and absolute size. One fixed scale factor per family keeps
    relative size comparable across participants.

Training augmentation is limited to small translations (up to 8 pixels),
brightness and contrast changes (up to 0.15), and light Gaussian blur
(probability 0.2, sigma 0.1 to 0.6). Rotation, scaling, shear, and flips are
never used, for the same reasons.

Sources: src/preprocessing/pipeline.py; src/utils/config.py
(PreprocessingConfig, AugmentConfig); src/data/transforms.py; CLAUDE.md.

================================================================================
5. FEATURES
================================================================================

5.1 Handcrafted features. Measured on the background-flattened original crop
(not the scaled model input), with pixel sizes converted to millimetres at
200 dpi. An ink mask (threshold 170 on the flattened crop) is used only to
measure.

  - Every crop: ink ratio, mean and spread of ink darkness, median and
    interquartile range of stroke width, ink bounding-box height and width,
    and number of connected components.
  - Stroke level, on the ink skeleton: variation of stroke width and of ink
    darkness along the stroke, a tremor index (deviation of the stroke from
    a smoothed path), mean segment length, and endpoints and junctions per
    centimetre. [CITE: skeleton-based stroke analysis] [CITE: tremor in
    handwriting]
  - Word and cursive crops: baseline angle, slant, core-zone (x-) height,
    gap between components, and right margin.
  - Drawing crops: share of the box covered by the drawing, horizontal and
    vertical position of its centre, share of ink in the lower half, figure
    height, a detail count, empty-space ratio, and an erasure score.

Pre-printed box rules near the crop edge are removed before measuring. Per
participant, each feature is summarized by its mean and standard deviation
within each task family. A missing value is filled with the median of the
same participant's other crops in that family, never pooled across
participants; every fill is logged.

5.2 Frozen ResNet18 embeddings. An ImageNet-pretrained ResNet18 (torchvision
weights IMAGENET1K_V1) is used as a fixed feature extractor [CITE: He et al., ResNet] [CITE: ImageNet]. Each crop gives a 512-dimensional embedding.
Embeddings are averaged per participant within each task family.

5.3 Exploratory handwriting-encoder embeddings. Embeddings from a
handwriting-trained encoder (microsoft/trocr-base-handwritten) are computed
for word and cursive crops [CITE: Li et al., TrOCR]. Its processor resizes
every crop to 384 x 384, which discards absolute size and aspect ratio.
These embeddings are therefore exploratory only.

Sources: src/features/handcrafted.py; src/features/strokes.py;
src/features/embeddings.py; src/features/embeddings_handwriting.py;
src/utils/config.py (FeaturesConfig, EmbeddingConfig,
HandwritingEmbeddingConfig).

================================================================================
6. MODELS
================================================================================

All models output a participant-level probability of SAD. A participant is
predicted SAD when that probability is 0.5 or higher. The threshold is fixed
and never tuned.

6.1 Majority baseline. Each outer fold predicts the majority label of that
fold's training participants.

6.2 Logistic regression on handcrafted features. Standardization followed
by logistic regression with balanced class weights [CITE: scikit-learn].
The regularization strength C is chosen from {0.001, 0.01, 0.1, 1, 10} by
stratified 5-fold inner cross-validation on macro-F1, using the outer
training participants only. Feature sets: all features (the main set), and
each task family alone.

6.3 Logistic regression on frozen embeddings. As above, with principal
component analysis between standardization and regression. PCA keeps at
most 64 components. Feature sets: the three family means side by side (the
main set), and each family alone. The exploratory handwriting embeddings use
the same pipeline.

6.4 Fine-tuned ResNet18. The first convolution is reduced to one input
channel by summing its pretrained colour filters. The stem and the first two
residual blocks are frozen; the last two blocks (layer3, layer4) and the
head are trained. The head is global average pooling, a 256-unit layer with
ReLU and dropout (0.5), and a 2-class output. Training uses AdamW
[CITE: Loshchilov and Hutter, AdamW] with learning rates 1e-3 for the head
and 1e-4 for the backbone, weight decay 1e-4, a cosine schedule, batch size
32, at most 100 epochs, and class-balanced cross-entropy. Training stops
early when inner-validation participant macro-F1 has not improved for 10
epochs; the best epoch is restored. One model is trained per task family.
Crop probabilities are averaged per participant, and the three families are
fused with equal weights.

6.5 CNN-HMM hybrid (the titled method). For word and cursive crops, the
fine-tuned network's layer3 feature map is averaged over height, giving one
256-dimensional vector per image column. Read left to right, these vectors
form a sequence, one per crop. The frames are standardized and reduced by
PCA, both fitted on training frames only. One Gaussian hidden Markov model
with diagonal covariance is fitted per class [CITE: Rabiner, HMM
tutorial] [CITE: hmmlearn]. The decision score is the length-normalized
log-likelihood difference between the SAD and HAPPY models plus the log
prior ratio. The model setting is chosen from 2, 3, 4, or 6 states, 8, 16,
or 32 PCA components, and an ergodic or left-to-right topology, by
inner-validation participant macro-F1 (2 restarts per candidate). The chosen
setting is refitted with 5 restarts and calibrated with Platt scaling on the
inner-validation participants [CITE: Platt]. Crop probabilities are
averaged per participant, and word and cursive are fused with equal weights.
Drawing is run only as a secondary analysis and is never fused.

A limitation follows from this design: the HMMs see features of images the
network was trained on. Selecting and calibrating on inner-validation
participants, whose images the network did not train on, reduces but does
not remove this optimism.

7. ANALYSIS DESIGN
================================================================================

The main analysis uses an extreme-groups design [CITE: extreme-groups
designs, e.g. Preacher et al.]. Participants whose adjusted totals lie
closest to the cutoff of 72 are set aside as a middle band, so the primary
set contrasts clearly HAPPY with clearly SAD participants.

The middle-band fraction was fixed at 0.20 on 2026-10-04, from labels.csv
score data only, before any model was run. Of the fractions previewed (0.20,
0.25, 0.30, 0.35, 0.40), 0.20 was the smallest that kept at least 100
participants in each class; all larger fractions left fewer than 100 SAD
participants. On the current labels this sets aside 57 participants and
keeps 228 in the primary set (126 HAPPY, 102 SAD), with kept adjusted totals
of 75 to 114 (HAPPY) and 42 to 69 (SAD). [MISSING: final counts at freeze]
[MISSING: adviser sign-off date on the analysis design decision]

The full sample, every participant who passed quality checks, is analysed as
a secondary set.

================================================================================
8. EVALUATION PROTOCOL
================================================================================

The protocol was written and approved before any model result existed. It is
frozen by a git tag. No model may run on real data before the tag; this is
enforced in code. [MISSING: freeze date and commit]

Unit of analysis. The participant. Crop-level models are aggregated by the
mean of the participant's crop probabilities.

Cross-validation. 5 outer folds, stratified on label and middle-band
membership, seed 42, over all labeled participants. A participant's crops are
never split across training and test, and this is checked in every fold.
Inside each outer training set, the CNN models hold out a stratified 15% of
participants for early stopping, HMM selection, and calibration; the
logistic regressions use 5-fold inner cross-validation. Scalers, PCA, and
models are fitted on training participants only. Nothing is tuned on outer
test participants. [CITE: nested cross-validation, e.g. Varma and Simon]

Metrics. The primary metric is participant-level macro-F1. Accuracy,
balanced accuracy, precision and recall per class, and ROC-AUC (SAD as
positive) are also reported. Metrics are computed once on the pooled
out-of-fold predictions, and per fold for all folds. Accuracy is always shown
next to the majority baseline. The target, not a hypothesis, is macro-F1 and
accuracy of at least 0.75 on the primary set (Deviation 1, raised from the
pre-registered 0.70 before any real result; stretch goal 0.80).

Uncertainty. 95% percentile confidence intervals come from 2,000 bootstrap
resamples of participants, seed 42 [CITE: Efron and Tibshirani, bootstrap].
Every model is compared with the handcrafted logistic regression as a paired
difference in macro-F1 on the same resamples.

Permutation tests. Within each outer fold, the labels of the training
participants are shuffled among them, the whole pipeline is refitted, and
test participants are scored against their true labels [CITE: Ojala and
Garriga, permutation tests for classifiers]. The p-value is
(1 + number of permuted macro-F1 at or above the observed) / (1 + number of
permutations). The two logistic regressions in the ensemble get 1,000
permutations. The CNN models and the ensemble get N = 20 full retrains on
the primary set (protocol section 4, Revision 3); the smallest attainable
p-value is then 1/21 = 0.0476. The significance level is 0.05.

The pilot (participants 001 to 100) is a technical check only and is not
reported as a result. Any change after the pilot is logged as a deviation.

Sources: EVALUATION_PROTOCOL.md sections 2 to 4 and 7; src/utils/config.py
(CVConfig, EvalConfig, PermutationConfig); src/training/splits.py;
src/training/evaluator.py; src/analysis/permutation.py.

================================================================================
9. PRIMARY MODEL AND SUPPORTING ENSEMBLE
================================================================================

The primary model is the fused CNN-HMM, the method named in the thesis
title. The primary claim is its participant-level macro-F1 on the primary
set, with its 95% confidence interval, shown against the majority baseline,
with its paired difference against the handcrafted logistic regression (all
features) and its permutation p-value from N = 20 full retrains. All other
models and sets are secondary.

The ensemble is a fixed supporting model: the equal-weight mean of three
participant probabilities, from the handcrafted logistic regression (all
features), the embedding logistic regression (family means side by side),
and the fused CNN-HMM. No weights are learned, and no component can be
added or dropped. Exploratory models are never included. It is reported in
full beside the CNN-HMM, with the same metrics, paired comparison, and
permutation test.

The frozen protocol named the ensemble as the primary model; the change to
the CNN-HMM was made after the results were seen and is logged as
Deviation 4 (EVALUATION_PROTOCOL.md section 9).

Sources: EVALUATION_PROTOCOL.md sections 5 and 9 (Deviation 4);
src/training/run_hybrid.py; src/training/run_ensemble.py.

10. SECONDARY AND EXPLORATORY ANALYSES
================================================================================

Secondary analyses are reported without correction for multiple
comparisons:

  - Macro-F1 per task family (drawing, word, cursive, combined) for every
    model.
  - The full sample, side by side with the primary set.
  - The middle band: models trained on primary-set participants predict the
    set-aside participants, scored against their export labels and shown
    next to the majority baseline.
  - Aggregation: mean of logits and majority vote, compared with the mean of
    probabilities.
  - Ablations: a simpler 4-block CNN and the ResNet18 head against the
    CNN-HMM; each ensemble component against the ensemble.
  - The handcrafted features with the largest mean standardized
    coefficients across folds (top 10), with their fold-to-fold spread.
  - Label balance of participants excluded at quality control against those
    included, by chi-square test, if any were excluded.
  - Grad-CAM maps of the fine-tuned network's last residual block (layer4),
    for the 4 most confident correct and incorrect predictions of each kind
    per task family, each from the fold model that made the prediction
    [CITE: Selvaraju et al., Grad-CAM].

Exploratory: the handwriting-encoder embeddings, compared with the ResNet18
embeddings. They are never part of a confirmatory claim.

Sources: EVALUATION_PROTOCOL.md section 6; src/analysis/secondary.py;
src/analysis/gradcam.py; src/utils/config.py (EvalConfig, GradCAMConfig).

12. PER-EXERCISE TRAINING (v3, EXPLORATORY)
================================================================================

This analysis was added at my adviser's request after all v1 and v2 results
were known. The question was which of the 24 FINALE exercises, taken one at
a time, carry information about the self-reported state. It is post hoc and
exploratory (Deviation 6). v1 stays the primary model, and no v1 or v2
output was changed.

Models. Each exercise (D1 to D4, the 15 word boxes W1_LH to W5_UC, and CS1
to CS5) is modelled on its own, with one image per participant and one model
per exercise and outer fold. There are four per-exercise models:

  - lr_handcrafted_v3: logistic regression on that exercise's handcrafted
    features, fitted as in section 6.2.
  - lr_embeddings_v3: logistic regression with PCA on that exercise's frozen
    ResNet18 embedding, fitted as in section 6.3.
  - cnn_head_v3: the fine-tuned ResNet18 of section 6.4, with the same
    settings, trained on that exercise's crops only.
  - cnn_hmm_v3: the column-sequence HMM of section 6.5 on that exercise's
    cnn_head_v3 network, with the same setting grid, chosen and
    Platt-calibrated on inner-validation participants. Unlike v1, drawing
    exercises are included.

Split. v3 uses the same primary set (n = 320), the same outer folds
(folds.csv) and the same labels as v1. Within each outer fold the inner
split is the one the CNN models use (15% of the training participants,
stratified, seed 42 + fold, drawn on the true labels), and it is the same
for all 24 exercises. This gives 217 inner-training, 39 inner-validation
and 64 test participants per fold. Every model checks that no participant
appears on two sides of a split.

Fixed combinations. Before any v3 result existed, I fixed how the
per-exercise probabilities are combined. cnn_head_v3_fused and
cnn_hmm_v3_fused are equal-weight means over the drawing exercises, the word
exercises, the cursive exercises, word and cursive together (word_cursive,
the counterpart of v1's fused CNN-HMM), and all 24 exercises (all24).
Nothing in a combination is learned.

Selected exercise. cnn_hmm_v3_selected is the only "best exercise" model. In
each outer fold it takes the one exercise whose cnn_hmm_v3 has the highest
inner-validation participant macro-F1 (ties go to the earlier exercise in
form order) and applies it to that fold's test participants. Only 39
participants per fold are used for this choice, so the chosen exercise can
change between folds by chance. This makes the row noisy, but no test
participant is involved in the choice.

Threshold and metrics. A participant is SAD when P(SAD) is 0.5 or higher.
Every v3 row reports macro-F1, accuracy, balanced accuracy and ROC-AUC with
2,000-resample bootstrap CIs (seed 42), the majority baseline, every fold
and the confusion matrix, as in section 8. Every row also gets a paired
macro-F1 difference from lr_handcrafted/all. The all24 row is also compared
with cnn_hmm_fused/fused, lr_embeddings/concat, cnn_head_fused/fused and
cnn_hmm_v2/task_order, and each family row is compared with the v1 model of
the same kind and family.

Permutation tests. Each per-exercise logistic regression gets N = 1,000
label permutations, as in section 8. Because each LR model is tested on 24
exercises, the p-values within each model are corrected with the
Benjamini-Hochberg false discovery rate at q = 0.05 [CITE: Benjamini and
Hochberg, FDR]. The CNN path gets only one test, cnn_hmm_v3_fused/all24,
declared before any v3 result. Per-exercise CNN rows are descriptive only.

How the number of CNN draws was set (D2). The CNN-path test retrains all 24
exercises in all 5 folds for every draw, so its cost had to be decided
first. The rule, written into Deviation 6 before training, was: after the
main cnn and hmm steps, take 20 x (cnn step time + hmm step time) from the
run logs; if that is at most 25 GPU-session hours, run N = 20, otherwise run
no CNN-path test. The main steps took 0.357 h (cnn) and 0.741 h (hmm) on one
NVIDIA L4, so 20 draws were projected at 21.96 h, under the 25 h budget. N =
20 was committed on 2026-10-28, before any v3 metric was computed. The
smallest attainable p-value is then 1/21 = 0.0476.

Imputation. Some handcrafted feature values of a single crop can be
missing. A missing value is filled from the same participant's other crops of that task family
(or a fixed 0.0 when there are none). No other participant and no label is
used. In v3 this means an imputed value for one exercise comes from the same
person's other exercises, so the number of crops with imputed values is
reported per exercise: from 0 (for example D1, W1_UC, CS1) up to 8 (W1_LH)
of the 320.

Checks. Before v3 ran, SHA-256 checksums of all v1 and v2 outputs on Drive
were stored. After v3, the same check found 0 changed, 0 missing and 0 new
files outside the v3 paths.
